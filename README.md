 Fitur Utama & Interaksi Gesture
Sesuai dengan ketentuan tugas untuk NIM kelompok, aplikasi ini menerapkan berbagai gestur interaktif dan struktur layout modern:

1. **Double Tap (Ketuk 2x):**
   * **Aksi:** Mengetuk kartu informasi dua kali secara cepat.
   * **Hasil:** Mengubah warna latar belakang kartu menjadi lebih pekat dan memunculkan ikon hati merah sebagai penanda interaksi suka (*like*).

2. **Scale / Pinch Gesture (Zoom In/Out):**
   * **Aksi:** Melakukan gestur cubit layar (*pinch*) atau menggunakan tombol navigasi zoom tambahan di layar.
   * **Hasil:** Memperbesar atau memperkecil ukuran kartu informasi secara proporsional dan dinamis.

3. **Swipe / Horizontal Drag (Geser Kiri/Kanan):**
   * **Aksi:** Mengusap layar secara horizontal pada area kartu.
   * **Hasil:** Berpindah antar halaman kartu informasi SDGs dengan mulus disertai pembaruan indikator halaman.
